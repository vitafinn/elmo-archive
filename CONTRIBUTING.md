# Contributing

This project is in maintenance mode. Please focus contributions on reproducible bugs and game compatibility. Discuss any feature proposal before doing implementation work; new features are not planned.

See docs/GUIDE.md for pinned build tools and `docs/LAUNCH.md` for preview release checks. Keep changes focused and include the relevant frontend and Go test results in pull requests.

Never add personal game history, account identifiers, connection tokens, certificate keys, database exports, or captured traffic to tests or screenshots. Use synthetic fixtures. Report suspected credential exposure privately through GitHub private vulnerability reporting if enabled; do not paste credentials into public issues.

Preserve upstream copyright notices and the GPL v3 license. Document known uncertainty in banner rules and probability models instead of presenting estimates as exact results.

Write short, clear action labels. Use natural sentences for explanations when more context helps. Follow ASD-STE100 principles where useful, without forcing sentence fragments or claiming formal compliance. Update English and Chinese messages together when behavior changes.

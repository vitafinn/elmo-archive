# Elmo Archive — 少女前线 2：追放抽卡记录工具

Windows 工具，可查看保底、人形与武器副本花费，以及服装访问记录。

**本项目是 [ElmoBeacon](https://github.com/MatchaCabin/ElmoBeacon) 的分支（fork）。** 原项目由 MccWiki 及贡献者维护。本分支独立维护，并非官方游戏工具。

[下载](https://github.com/vitafinn/elmo-archive/releases) · [反馈问题](https://github.com/vitafinn/elmo-archive/issues) · [English](../README.md)

## 安装

需要 Windows x64、Windows 游戏客户端和 [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)，无需另装代理软件。

1. 在 Releases 下载 **windows-x64.zip**，不要选择“Source code”。若 Releases 为空，表示尚未公开发布。
2. 解压到可写文件夹，运行 `ElmoArchive.exe`。

当前为早期预览，程序未签名。已实现 Darkwinter 和 Haoplay（全球、亚洲、日本、韩国）的导入路径，但各区服测试尚未完成。不支持国服客户端。

## 导入记录

1. 打开游戏并登录。
2. 在软件中选择“导入记录”，使用手动 UID 方式，填写游戏个人资料中的 UID。
3. 开始连接。如果出现证书设置，请核对软件与 Windows 提示中的名称和指纹。只有内容一致且你信任软件时才选择“是”。窗口被遮挡时，可点击“显示 Windows 确认窗口”。
4. 在游戏中打开正在进行的卡池 → 详情 → 侧边的“访问记录”。如果已经打开，请关闭后重新打开。无需抽卡或购买。
5. 软件显示历史连接就绪后，选择“同步记录”。核对 UID 和区服，再确认导入。等待“同步完成”。

Darkwinter 用户也可选择网页商店登录方式。按软件提示操作，等到 UID 抓取完成后再打开游戏访问记录。商店与游戏必须登录同一账号，软件无法自动核实两者是否一致。

**下次更新记录：** 直接选择“同步记录”，仅在连接失效后重新连接。请保持相同的 UID 和导入方式。

## 证书与本地数据

抓取临时使用本地 HTTPS 代理及受信任根证书。根证书会获得实际的安全权限，请先阅读设置说明再决定是否安装。默认在导入成功后移除信任，也可在“导入记录 → 抓取与证书”中手动移除。有效的已保存连接无需重新安装证书即可同步。

请保留软件文件夹。更新前关闭软件并备份 `ElmoBeacon.db`。不要公开数据库、连接配置、游戏日志或 `ca.key`（证书私钥）。软件会在证书设置中显示存放位置。

若异常退出后无法联网，请在 Windows 的网络代理设置中检查是否仍指向 `127.0.0.1:8899`，并恢复原设置。更多信息见[详细说明（英文）](GUIDE.md#capture-privacy-and-troubleshooting)。

## 查看统计

- 自选与重逢每期保底独立，到期失效；服装记录按赛季分组。
- 点击结果可查看副本、上次未命中的花费，以及记录完整时的 V6R1、V6R6 等组合花费。
- 标签有误时使用“编辑目标结果”，不确定时选择“未知”。
- 统计来自导入记录，并非实时背包。运气数值为估算，缺失记录会影响统计。
